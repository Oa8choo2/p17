# Reviewing documentation texts in a github repo

The most important part is: get the review done, give feedback
to the authors.

Review is not equal to rewrite. 

- assume the author has reviewed the text

- start by reading the text,
  then verify if the text 'works'
  try to achieve what is mentioned in the text

  e.g. with the text on ssh: try to make a key pair based on the text

- start a review meeting with the original author

- print the page from the online website,
  annotate (with a pencil or pen) on the printout,
  give to the original author

- if you have basic github skills
- use of the online, web interface is ok

- go to the text in the repo, 
  click on the left column,
  make an issue

- use github discussions?
