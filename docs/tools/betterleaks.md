# Betterleaks

## What is betterleaks

A secret scanner, it scans your texts, code, ... for patterns that resemble to passwords, keys, etc.

In the past it was known as gitleaks.

## Installation

```bash
# Go
go install github.com/betterleaks/betterleaks@latest
```

## Usage

When used on a repo, cd to that repo (locally checked out) and

```bash

betterleaks git --verbose 
```
