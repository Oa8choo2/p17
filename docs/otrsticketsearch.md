# Otrs / Znuny ticket search

To search for a ticket directly from the url use this:

https://otrsdict.ugent.be/znuny/index.pl?Action=AgentTicketSearch;Subaction=Search;TicketNumber=

and add the ticketnumber at the end

This is then translated to an url with the ticketid (6 characters)

https://otrsdict.ugent.be/znuny/index.pl?Action=AgentTicketZoom;TicketID=123456
